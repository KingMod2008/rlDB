# KingMod

Latest client: **2026.10.28.0004**. Release news is available in the [changelog](CHANGELOG.md).

Download [KingMod Setup](https://raw.githubusercontent.com/KingMod2008/rlDB/main/KingMod-Setup.exe) to install the current client. Setup has separate Reinstall and Update actions. Update is available only for a newer release; new update notices appear inside KingMod.

[KingMod Catalog Images](https://raw.githubusercontent.com/KingMod2008/rlDB/main/KingMod-Catalog-Images.exe) exports item previews from your local game installation.

This repository contains public item and title metadata, paint and rarity lists, previews, Lua extensions and texture collections. Plugin files include checksums for reliable downloads. Only the current client release is retained in the releases folder. Publishing tools and private runtime files are kept outside the public repository.

Match Tools and Opponent/Player Boost are no longer offered in the public extension catalogue. Existing local plugin settings are not part of this database.

Original texture authors, descriptions and license terms are preserved inside each archive.

## Custom UI Changer

Open **Textures → Game UI** in KingMod to preview and apply a pack. The collection contains 40 custom packs and the default interface, including Galaxy, Voxel Kingdom, Manga Midnight, Dungeon Forge, Candy Circuit, Holo Station and KingMod Carbon.

The current [UI catalogue](patches/ui-themes-github.json) uses UI format 2 for high-resolution backgrounds and pixel-shaped controls. Use a compatible KingMod client. Older clients keep their bundled themes.

Close Rocket League before applying a theme. You can restore the original interface from the same page.

## Free and Premium

KingMod opens in Free mode without a key. Spawn ordinary items and titles into your local collection, use your own local item customizations, and access Sync Inventory and restoration. Activate a key in **Settings > Free & Premium**.

Premium includes match-title display, shared Premium cosmetics, ping customization, opponent boost, Original player names, Rocket Pass display overrides, KingMod-created drop spawning/opening, rank and season-reward display overrides, and hiding goal explosions or demolition smoke. Paid controls are disabled in Free mode. Genuine Rocket League inventory, drops and progression remain available.

Expired or revoked Premium access automatically resets paid settings and cancels queued paid drops. Free item and title collections remain available.

Close Rocket League before updating or changing tiers so previously loaded native changes can be restored or rebuilt.
