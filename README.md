# KingMod

Download [KingMod Setup](https://raw.githubusercontent.com/KingMod2008/rlDB/main/KingMod-Setup.exe) to install the current client. Setup has separate Reinstall and Update actions. Update is available only for a newer release; new update notices appear inside KingMod.

[KingMod Catalog Images](https://raw.githubusercontent.com/KingMod2008/rlDB/main/KingMod-Catalog-Images.exe) exports item previews from your local game installation.

This repository contains public item and title metadata, paint and rarity lists, previews, Lua extensions and texture collections. Plugin files include checksums for reliable downloads. Only the current client release is retained in the releases folder. Publishing tools and private runtime files are kept outside the public repository.

Original texture authors, descriptions and licenses inside archives are preserved. The texture collections were mirrored from the public Hebnix patch catalog at the owner's request and retain their original ownership and license terms.
