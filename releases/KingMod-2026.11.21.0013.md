Your Garage, your style

This update brings more control over your car's appearance, connects the KingMod app with the in-game Garage, and makes profile customization easier to use.

- Reworked Garage appearance page with native selectors, sliders, color controls, clearer spacing and visible Blue/Orange team selection.
- Separate styles for both teams, with primary and accent paint, underglow, supported headlights and tail lights, HUD colors and stadium colors.
- Original, Solid, Neon, Rainbow and Pulse modes, plus palette choices and custom RGB colors for supported appearance channels.
- Live wheel stance controls: adjust camber, move wheels inward or outward, and change their vertical offset while viewing the car in Garage.
- Select all wheels, front wheels or rear wheels, with reset controls to return the selected team's stance to default.
- Shared appearance settings between the desktop app and Garage. Changes from either place save to the same team profile and appear in the other controls.
- Desktop appearance updates reach the Garage preview without another game restart after verified setup. Changes are grouped into a single preview refresh.
- Separate Name changer and Name spoofer controls. The local changer gives you a chosen name in your own match displays, with an option to return to your normal name.
- Rank changer with per-playlist settings, an option to copy 2v2 settings to other ranked modes, season reward display controls and a refresh action.
- Ping changer with a chosen reported ping value and a real-ping fallback.
- Automatic saving, clearer apply status and faster repeated setup checks. Verified native appearance edits can apply without preparing the game packages again.

Close Rocket League and KingMod before updating, then open KingMod first so setup can finish. Appearance and profile changes are delivered from the main menu or Garage; edits made during a match wait until you return there and carry into the next match. Reopen Ranked to refresh its tiles.

Rank and season reward options change local displays. Ping customization changes the reported value; actual connection latency stays the same. The local Name changer changes your own display, and the separate Name spoofer takes effect at the next account-name lookup.

Gold Rush (Alpha Boost) color, wheel texture recolors, map/ball replacements and other package-only effects still need preparation with Rocket League closed. Existing Premium requirements apply.
